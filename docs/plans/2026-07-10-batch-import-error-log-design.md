# 批量导入错误日志导出设计

## 目标

批量导入结束后，只要存在错误，用户可以将全部错误导出为 Excel，离线筛选、定位并修正源数据。

## 交互

- 在批量导入对话框底部显示“导出错误日志”按钮。
- 仅当导入已停止且错误列表非空时可用。
- 点击后打开现有原生保存对话框，默认文件名包含数据库名与时间。
- 保存成功或取消均不改变当前导入结果，保存失败显示在底部状态栏。

## 文件内容

工作簿名为“批量导入错误日志”，每条错误占一行，列顺序固定为：来源文件、工作表、目标表、Excel 行号、字段、原值、错误原因。

错误信息缺少某个维度时保留空单元格。日志值继续使用现有 Excel 单元格长度保护，避免超长数据库错误导致工作簿无法打开。

## 实现边界

- 日志格式化和保存放在 `useBatchTransfer`，复用现有 XLSX 加载与 `save_export_file` 后端命令。
- `BatchImportDialog` 只负责展示按钮和调用 composable，不持有导出逻辑。
- 不改变单表导入、不新增后端命令、不自动导出。

## 验证

- 单元测试验证列头、错误字段映射、默认文件名及保存调用。
- 组件结构测试验证按钮只在错误存在时出现。
- 运行批量导入、值校验、前端构建和 Rust 校验测试。
