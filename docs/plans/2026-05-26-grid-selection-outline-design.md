# Grid Selection Outline Design

**Status:** Approved on 2026-05-26

## Goal

Match Excel-style cell selection feedback in the data grid: a single selected
cell has only a uniform perimeter outline, while a multi-cell range has a
uniform perimeter outline, subtle range fill, and an unfilled anchor cell.

## Selected Design

- Keep the existing range state and edge classes generated by
  `useGridEditor.js`; the render state already identifies the rectangular
  perimeter and its anchor cell.
- Render selection entirely through `workbench.css`.
- Make the selection perimeter a continuous, consistent 2px stroke on all
  four outer edges. Its drawing layer must cover cell-grid intersections so
  the perimeter does not break into one segment per cell.
- Do not recolor individual cell borders in a selected range. The existing
  neutral grid lines remain visible inside the selected rectangle.
- Remove selection fill from a single selected cell. For multi-cell ranges,
  apply the existing subtle accent fill to selected cells except the anchor,
  which retains its normal cell background.
- Preserve the same continuous perimeter for one-row and one-column ranges,
  where one cell may contribute both opposing sides of the outline.

## Affected Code

- `src/workbench/workbench.css`: correct the outline and range-fill rules.
- `src/workbench/workbenchShell.test.js`: guard the CSS contract against
  border recoloring, segmented perimeter drawing, and filled anchors.

- Run `node --test src/workbench/*.test.js`.
- Run `npm run build`.
- Inspect single-cell and rectangular drag selections in the browser-only
