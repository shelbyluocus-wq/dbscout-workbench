# 数据库首页与表对象管理设计

- 日期：2026-07-07
- 状态：已提出设计，待用户审阅
- 目标区域：当前空白工作区，也就是未打开表时中间主区域

## 1. 产品目标

把当前“从左侧打开一张表”的空白区升级为每个数据库的固定首页。首页不是一次性空状态，而是当前数据库的表对象管理入口：用户选中数据库后可以在主工作区直接浏览表、排序、搜索、多选、复制、粘贴、重命名、删除，并双击打开表数据。

最终体验应接近 Navicat 的对象管理页：左侧树负责导航，首页负责当前库的表级管理，数据标签负责查看和编辑单张表。

## 2. 用户可见行为

### 2.1 首页入口

- 选中一个数据库后，中间区域默认显示该数据库首页。
- 首页在表打开后仍可返回，不会被第一张表永久替代。
- 每个数据库最多有一个首页入口，表现为标签栏里的“首页”或数据库名首页标签。
- 切换数据库时，首页内容同步切到新数据库的表列表。
- 没有连接或没有选中数据库时，仍显示轻量引导状态，提示先选择或创建连接。

### 2.2 首页布局

首页采用密集的桌面工具布局，不做营销式大卡片：

- 顶部对象栏：显示数据库名、表数量、当前排序、已选数量和刷新状态。
- 工具栏：搜索表名/备注、排序下拉、刷新、复制、粘贴、重命名、删除。
- 表对象区：默认“表对象标签列表”，视觉上像一排排可选中的表标签，保留列表密度和虚拟滚动。
- 底部状态提示：展示最近一次复制、粘贴、重命名、删除、刷新结果。

表对象标签展示：

- 表名，作为第一视觉重点
- 表备注
- 字段数（有 schema 时显示，未加载时为空或骨架）
- 行数（可用时显示；不可低成本获取时不强行扫全表）
- 选中、悬停、只读、正在重命名、操作失败等状态

## 3. 交互规则

### 3.1 选择与打开

- 单击表：选中该表。
- Ctrl/Shift 单击：多选或范围选择。
- 双击表：打开表数据标签。
- Enter：打开当前选中表。
- Esc：清空选择或关闭正在编辑的重命名输入。
- F2：对唯一选中的表进入重命名。
- Delete：触发删除确认。

侧栏表节点的单击打开行为可以保留；首页里的表对象按桌面对象管理习惯，单击只选择，双击才打开。

### 3.2 搜索与排序

首页搜索只筛当前数据库的表对象，匹配表名和备注，不触发全库值搜索。

排序支持：

- 名称升序
- 名称降序
- 备注优先
- 最近打开优先
- 原始顺序

默认使用名称升序。排序设置按当前数据库持久化到本地，不影响后端真实表顺序，也不改变左侧树的既有排序策略，除非后续单独设计统一对象排序。

### 3.3 复制与粘贴

首页中的复制是“复制表对象”，不是复制表名文本。

- 选中一张或多张表后按 Ctrl+C 或菜单“复制”，把表引用写入应用内剪贴板。
- 在同一数据库首页空白处按 Ctrl+V 或右键“粘贴”，复制所选表到当前数据库。
- 在另一个数据库首页粘贴，复制到目标数据库。
- 粘贴完成后刷新目标首页和侧栏，并选中新生成的表。
- 粘贴失败时保留原选择并显示可读错误。

重名规则：

- 若目标库没有同名表，保留原表名。
- 若目标库已有同名表，生成 `表名_copy1`。
- 若 `表名_copy1` 已存在，继续使用 `表名_copy2`、`表名_copy3`。
- 大小写比较遵循当前后端数据库的可行规则；前端展示统一按“不产生可见重名”处理。

现有复制后端里首个候选可能是 `_copy`，本设计要求统一成 `_copy1` 起步，前端 mock 和 Rust 路径保持一致。

### 3.4 重命名

- F2 或右键“重命名”进入行内编辑。
- 只有单选时可重命名。
- 输入为空、未变化、包含明显非法字符时不提交。
- 与现有表名冲突时阻止并提示。
- 成功后同步更新首页、侧栏、已打开的数据标签和设计标签。
- 只读连接禁用重命名，并在工具栏和菜单中显示禁用状态。

### 3.5 删除表

删除表是正式危险操作，必须做完整闭环：

- 支持单表和多表删除。
- 只读连接禁用删除。
- 删除前弹出确认，明确列出将删除的表名；多表删除时显示数量和前若干表名。
- 确认按钮使用危险样式，文案为“删除表”或“删除 N 张表”。
- 后端执行真实 drop table，并记录 DDL 审计；无法行级回滚，提示依赖快照恢复。
- 成功后刷新首页和侧栏。
- 被删除表如果已有数据标签或设计标签打开，需要关闭这些标签，或用“表已删除”的错误状态替代；本设计选择关闭相关标签并在状态栏说明。
- 部分失败时显示失败列表，成功删除的表仍从首页移除。

### 3.6 右键菜单

表对象右键菜单：

- 打开
- 表设计
- 重命名
- 复制
- 粘贴到当前库（当应用内剪贴板有表对象时显示）
- 删除
- 刷新

首页空白区右键菜单：

- 粘贴到当前库（当应用内剪贴板有表对象时可用）
- 刷新
- 排序子菜单

标签栏空白区原有分屏菜单保留，但首页内容区右键应优先处理表对象管理菜单，避免和全局刷新菜单互相抢事件。

## 4. 架构设计

### 4.1 首页模型

在工作区状态里新增首页型标签：

- `kind: "home"`
- `connectionId`
- `database`
- `sortMode`
- `query`
- `selectedTableNames`
- `clipboardFeedback`
- `loadingState`

首页标签与数据标签、设计标签共用现有 pane/tab 基础设施。这样分屏、聚焦、关闭、恢复布局都能沿用现有标签系统。

### 4.2 前端组件

新增组件：

- `DatabaseHome.vue`：首页容器，负责工具栏、表对象区、空状态和键盘事件。
- `DatabaseTableList.vue`：虚拟化表对象标签列表，负责选择、双击打开、F2 重命名、右键。
- `useDatabaseHome.js`：首页状态与行为封装，负责筛选、排序、多选、剪贴板、操作可用性。

复用现有能力：

- 打开表：沿用现有 openTable 流程。
- 重命名：复用现有 rename_table 命令，并把入口从弹窗升级为首页行内编辑。
- 复制：复用 copy_tables 命令，但增加同库/跨库粘贴的首页入口。
- 只读判断：沿用现有连接只读判断。
- 确认框：沿用全局确认框视觉体系。

### 4.3 后端命令

需要补齐或调整：

- `drop_tables`：新增批量删除表命令，MySQL 路径执行 DROP TABLE，demo/mock 路径同步删除 schema 和行缓存。
- `copy_tables`：重名命名规则改为 `_copy1` 起步，确保 Rust 和 mock 一致。
- `rename_table`：保留现有命令；前端增加提交前校验和行内错误展示。

ClickHouse 或其他只读连接：

- 首页仍可浏览、排序、搜索、打开。
- 复制、粘贴、重命名、删除、导入等写入动作禁用。

### 4.4 状态同步

表对象变更成功后必须同步：

- `workspace.tables`
- `workspace.schema`
- 左侧侧栏表列表
- 当前首页列表
- 打开的数据标签和设计标签
- 状态栏反馈

删除时关闭相关标签；重命名时更新相关标签；复制/粘贴时目标库刷新并选中新表。

## 5. 错误、加载和空状态

加载中：

- 首页显示表列表骨架，不在中心放大 spinner。
- 工具栏刷新按钮显示忙碌状态。

空库：

- 显示“当前数据库暂无表”。
- 若可写，提供粘贴入口；若后续支持建表，可在这里接入“新建表”。

错误：

- 表列表加载失败显示重试。
- 复制/粘贴失败保留剪贴板和选择。
- 删除部分失败显示成功数量和失败表名。
- 重命名失败保持行内编辑状态，方便用户改名重试。

## 6. 非目标

- 不在本次新增“新建表”完整流程；已有表设计入口保持可用。
- 不把左侧树重做为 Navicat 完整对象树。
- 不实现图标大网格视图作为首批必需项；默认表对象标签列表先做到完整、稳定、可验证。
- 不做拖拽复制表；复制/粘贴先用键盘、菜单和工具栏。
- 不强制为所有表计算精确行数，避免首页打开大库时变慢。

- 浏览器或 Tauri 开发环境手测首页：搜索、排序、双击打开、F2 重命名、复制、空白粘贴、重名、删除、只读禁用、标签同步。

## 8. 验收清单

- 选中数据库后主区域显示可用首页，而不是空白提示。
- 首页展示当前数据库全部表，并支持搜索与排序。
- 首页表对象单击选择、双击打开。
- F2 可重命名单个选中表。
- 可复制一个或多个表对象。
- 可在首页空白处粘贴表。
- 重名粘贴按 `_copy1/_copy2` 规则生成。
- 可删除单表或多表，并有危险确认。
- 只读连接下所有写入动作禁用。
- 复制、粘贴、重命名、删除后侧栏、首页和已打开标签状态一致。
- 大表库下首页仍然可用，不因一次性渲染全部 DOM 卡顿。
