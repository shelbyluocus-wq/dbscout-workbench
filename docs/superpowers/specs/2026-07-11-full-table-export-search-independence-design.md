# 单表导出与表内搜索解耦设计

## 背景

单表导出会创建独立的分页读取会话，以便导出未加载到界面的全部数据。当前实现把活动标签页的表内搜索词作为分页过滤条件传入，因此导出内容错误地缩小为搜索命中的行。

## 目标行为

- 单表导出始终导出当前表的全部行，不受表内搜索词、搜索模式或命中位置影响。
- 当前列排序继续应用于导出，仅改变完整数据的排列顺序，不改变导出范围。
- 导出继续使用独立分页会话读取全部行，不依赖界面当前已加载的数据量。
- 空表、文件命名、保存失败回退和成功反馈等既有行为保持不变。

## 方案

在单表导出的分页请求构造处移除搜索过滤条件，只保留页码、分页大小和当前排序。首个分页请求与后续分页请求使用同一规则，确保整次导出的数据范围一致。

不新增后端导出接口，也不复用界面内存中的可见行：现有独立分页读取已经能够完整覆盖大表，修正请求边界即可解决根因。

## 测试

调整单表导出的分页回归测试：构造一个带搜索词、搜索模式和排序的活动标签页，断言首个及后续分页请求均不包含过滤条件，但继续包含排序；最终生成的工作簿应包含所有分页返回的行。

运行单表导出测试，并运行全部前端 JavaScript 单元测试确认无回归。
