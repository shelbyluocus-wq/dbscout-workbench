# 2026-06-05 工作日志

## 修复 GitHub 拉取失败

- **问题**：GitHub Desktop 拉取时报 `Recv failure: Connection was reset`，直连 GitHub 被重置。
- **诊断**：检查发现系统环境变量 `HTTP_PROXY=http://127.0.0.1:7892` 已存在，但 Git 未配置代理，导致不走代理直连失败。
- **解决**：为仓库配置 Git 代理指向本地 7892 端口，随后 `git pull origin main` 成功（Fast-forward，cb0ff84 → d34ea67，28 个文件变更）。
- **命令记录**：
  ```bash
  git config http.proxy http://127.0.0.1:7892
  git config https.proxy http://127.0.0.1:7892
  git pull origin main
  ```
