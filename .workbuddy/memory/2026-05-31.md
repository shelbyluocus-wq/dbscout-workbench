# 2026-05-31

## 左侧资源树拖拽排序动画优化

**修改文件：**
- `src/workbench/components/WorkbenchSidebar.vue`
- `src/workbench/workbench.css`

**核心改动：**

1. **不再拖拽期间重排数组**：`previewConnections`/`previewDatabases` 改为始终返回原始顺序，视觉反馈由 CSS 驱动。

2. **Ghost 塌缩（source 位置）**：
   - 拖拽的源节点塌缩为 4px 高度、0.09 透明度、虚线边框的幽灵占位符
   - 子元素完全隐藏 (`opacity: 0`)
   - 过渡动画：`0.25s cubic-bezier(0.2, 0.82, 0.2, 1)`

3. **插入槽位（target 位置）**：
   - `is-drop-before`：target 上方 margin 扩大至 34px（连接）/ 32px（数据库）
   - `is-drop-after`：target 下方 margin 扩大至连接 34px（连接）/ 32px（数据库）
   - margin 过渡：`0.28s cubic-bezier(0.16, 1, 0.3, 1)` spring 缓动

4. **槽位视觉指示器**：
   - `::before`/`::after` 伪元素在间隙中渲染虚线框预览
   - 动画：`wb-slot-appear` keyframe（scaleY + opacity）
   - 颜色使用 `var(--wb-accent)` 和 `var(--wb-accent-soft)`

5. **类名绑定移至外层 section**：拖拽类名从按钮移到 `.wb-source-connection`/`.wb-source-database` 外层。

6. **全局拖拽光标**：`.wb-source-tree:has(.is-drag-ghost) .wb-tree-row { cursor: grabbing; }`

**验证结果：**
- Ghost 效果：`minHeight: 4px, opacity: 0.09, borderStyle: dashed` ✓
- Slot gap：`marginBottom: 34px`（after 位置）✓
- Slot 虚线框：`height: 28px, border: 1.5px dashed var(--wb-accent)` ✓
