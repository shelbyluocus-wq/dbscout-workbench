## Bug 修复：白屏

**原因**：`MySqlWorkbench.vue` 中新增的 `workbenchStyle` computed 使用了 `sidebarWidth`，但未从 `usePaneResize()` 解构出来，导致 JS 运行时 `ReferenceError`，Vue 无法挂载。

**修复**：在 `usePaneResize()` 解构中补充 `sidebarWidth` 和 `inspectorWidth`。

**教训**：修改 Vue 文件时，若引入新的响应式变量引用，必须确认其已在对应 composable 的返回对象中解构。

## 第三轮：分割线拖拽 hit area 扩大

用户反馈 1px 分割线太难选中，要求扩大可拖拽范围，同时注意滚动条避让。

**方案**：
1. **CSS**：`.wb-pane-divider` 改为 `flex: 0 0 5px; margin: 0 -2px`。实际渲染宽度 5px（向两侧各扩展 2px），但在 flex 布局中仍只占用 1px 空间，不影响面板间距
2. **JS**：`usePaneResize.js` 中 `startX` 不再用鼠标点击位置，而是用 divider 元素的中心线（`getBoundingClientRect()` 计算）。这样即使用户点在扩展区域边缘，拖拽时也不会产生偏移感
3. **滚动条处理**：2px 的扩展区域很小，不会覆盖滚动条的主要操作区域（滚动条通常 8-17px 宽）。暂不做复杂的滚动条检测，先以简洁方案交付

### 修改文件
- `src/workbench/workbench.css` — divider 宽度与 margin 调整
- `src/workbench/composables/usePaneResize.js` — 拖拽起始点改为 divider 中心线
