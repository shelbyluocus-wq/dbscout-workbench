## Design Critique — DB Scout Workbench UI
- Ran `/impeccable critique` on `src/workbench/MySqlWorkbench.vue` and component tree.
- **Score: 26/40** (Acceptable band). 0 P0, 2 P1, 3 P2 issues.
- Key findings:
  1. **Border overuse** — every panel/tab/dialog has 1px border, creating cumulative visual noise. Fix: remove 70% of borders, use background tints + spacing for depth.
  2. **Flat typography** — everything is 11-12px, no hierarchy. Fix: establish rem-based type scale (11/12/13/14px tiers).
  3. **Empty state bare** — single line of text, no CTA or icon. Fix: add icon + primary/secondary action buttons.
  4. **Tab design dated** — 2010s browser-tab style with borders and radius. Fix: minimal tabs with accent underline.
  5. **Button/input inconsistency** — varying heights, radii, border styles across components. Fix: unify to 3 button types + standard input style.
- Strengths: bespoke CSS icon system, sophisticated range-selection pseudo-element borders, comprehensive theme token infrastructure.
- Detector unavailable (bundled missing), assessment independence degraded.
- Snapshot persisted to `.impeccable/critique/`.

## Sidebar Background Fix — Eliminating Header/Tree Color Seam
- Modified `src/workbench/workbench.css`.
- **Root cause**: User reported header and tree in sidebar did not blend into a unified surface. Diagnosed as `backdrop-filter: blur(18px)` on `wb-sidebar` interacting with `wb-workspace`'s gradient background and `wb-source-tree`'s `overflow: auto`, causing subtle color/rendering differences between the header (top) and tree (scrollable) areas.
- **Fix**:
  1. Removed `.wb-sidebar` from the `@supports (backdrop-filter)` rule so sidebar no longer has glassmorphism blur.
  2. Added theme-specific opaque background overrides for `.wb-sidebar`:
     - Light: `#f0f2f5`
     - Dark: `#161d26`
  3. These colors approximate the previous `var(--wb-tree-surface)` semi-transparent look when composited over the workspace background, but are fully opaque, guaranteeing zero rendering variance between header and tree.
- **Result**: Sidebar now renders as a single continuous opaque panel. Header (`transparent`) and tree (`transparent`) both sit on the exact same solid background, completely eliminating any visible seam.
