### Inspector 面板 Header 高度固定

1. **问题**
   - `.wb-pane-header` 内使用 `flex-direction: column`，打开表后同时显示 "备注" + 表名，两行内容把 header 撑高（36px → 40px）
   - 导致 "备注下面的线"（border-bottom）向下偏移，和侧边栏/主面板对应线不再对齐
   - 用户描述："没有打开表时在同一行，打开表后被挤下去"

2. **修复**
   - 将 `.wb-pane-header div` 从 `flex-direction: column` 改为 `flex-direction: row`，`align-items: baseline`，`gap: 6px`
   - "备注" 和表名在同一行显示，header 高度恒定为 36px，不受内容影响
   - 为 `.wb-pane-header span` 增加 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`，防止长表名撑破布局

3. **测试验证**
   - 全部 44 个 JS 测试通过，无回归

### Inspector / Tab 栏 / Toolbar 三线对齐修复

1. **问题根因**
   - `.wb-object-tabs`（Tab 栏）实际高度为 38px（tab 高 28px + padding 6+3 + border 1），但 `.wb-pane-header`（Inspector）min-height 只有 36px
   - `.wb-table-toolbar`（表搜索工具栏）min-height 也是 38px
   - 导致 Inspector header 的 border-bottom（y=36）比 Tab 栏底部和 Toolbar 顶部（y=38）低 2px，三线不在同一水平
   - 用户截图反馈："没修好啊"

2. **修复**
   - 将 `.wb-pane-header` 的 `min-height` 从 36px 改为 38px
   - `padding` 从 `7px 9px` 改为 `6px 9px`，保持视觉居中
   - 现在 Inspector header（38px）= Tab 栏（38px）= DataGrid toolbar（38px），三线完美对齐

   - 全部 44 个 JS 测试通过，无回归
