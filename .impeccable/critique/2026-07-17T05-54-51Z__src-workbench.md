## 反模式判定

**LLM 评审：通过，无 AI 生成感。** "Earned familiarity" 成立：经典三栏、28px 高密度行、两行式列表头、split button、虚拟滚动——品类约定执行得比多数同类更克制。无营销渐变、无卡片网格、主色是石板灰而非"AI 紫"。150+ 个 `--wb-*` token、明暗双主题逐变量对齐、搜索命中徽章自成色彩语言，设计系统意图明确。

**确定性扫描（Assessment B）**：CLI 扫 `src/workbench` exit 2，12 条发现——`layout-transition`×10（8 处在 workbench.css 的 width/height 过渡，分栏/折叠动画，判定为有意设计；2 处在测试文件为误报）、`broken-image`×1（误报：命中的是 JS 正则字面量）、`side-tab`×1（误报：blockquote 引用竖线）。浏览器注入 7 个视图共采 15–24 条/视图，其中 `clipped-overflow-container`（虚拟滚动+分栏外壳，架构使然）、`repeating-stripes-gradient`（表格图标字形）为误报；`flat-type-hierarchy`/`cramped-padding` 属高密度工具的合理选择；`nested-cards`×3 机制命中属实但轻微。

**检测器补上的实锤**：`text-overflow`——Agent 面板头部项目选择器文字溢出 49px（与 LLM 发现的"Agent 头部说明被截断"互相印证）；暗色下 4 条 low-contrast（用户已声明无障碍出围，仅记录）。

**LLM 独有发现**（检测器无法覆盖）：危险确认按钮无红色语义、删除文案与回滚能力矛盾、英文标题、功能发现性、深色右缘黑带、浮层透明度脏。

## 总体印象

这是一个完成度明显高于同类开源产品的桌面工具：密度、状态反馈、快捷操作都是一流的，"数据仪器"定位兑现了。最大的机会不在加法而在收尾——高风险操作处的视觉刹车缺失、几处透明度/黑带类的精致度瑕疵、以及核心差异化功能（表设计）藏在右键菜单里。

## 做得好的

1. **单元格选中四联态**：选中一格，行/列十字高亮 + 检查器滚动定位 + 右下"当前字段/主键值"身份芯片 + 底部编辑器同步取值。全产品最有仪器感的设计。
2. **备份中心信任设计**：变更日志逐行带类型/状态徽章 + 逐行回滚按钮，安全能力做成可见可操作的清单。
3. **搜索命中色彩语言**：侧栏搜索与 Quick Open 共用表名蓝/备注琥珀/字段紫/字段备注青/值粉的徽章体系，结果即扫即懂。

## 优先问题

1. **[P1] 危险确认对话框没有任何危险视觉。** `ConfirmDialog.vue:53` 绑定 `wb-dialog-danger` 类，但全项目无任何对应 CSS 规则（已 grep 实锤）——删除行/删表/覆盖同步/移除连接的确认按钮与普通深灰主按钮一模一样；而同步对话框第一级自带红色按钮，第二级确认反而变灰，危险信号在最后一刻消失。修法：补 `.wb-dialog-danger` 规则（`--wb-danger` 底+白字+hover 加深），按 `workbenchCssPolish.test.js` 模式加防回归测试。
2. **[P1] 删除确认缺对象身份、文案与产品能力自相矛盾。** "删除 game_db.player 的当前行？此操作不可撤销。"——不说哪一行，且"不可撤销"与备份中心逐行回滚能力直接冲突（删表确认同款问题）。修法：文案带主键身份（"删除 game_db.player 中 id=3 的行"）；改为准确表述（"已记录变更日志，可在备份中心回滚"），或确认后 toast 给回滚入口。
3. **[P2] Agent 首印象是全中文界面里唯一的英文模板。** `AgentPanel.vue:141` 硬编码 "How can I help with this database?"；头部"未接入项目"+说明文字溢出 49px（检测器实锤）；三条建议芯片第三条直接诱导写操作。修法：标题中文化、修头部溢出、写操作芯片标注"需审批"或换读操作示例。
4. **[P2] 表设计（DDL 编辑器）只能右键发现。** 工具栏有冻结/导出/导入/分屏，唯独没有"设计"入口；核心差异化功能发现率极低。修法：工具栏溢出菜单加"表设计"，或检查器顶部加入口。
5. **[P3] 视觉精致度收尾包。** 深色模式网格右缘纯黑竖带（像渲染破洞）且 NULL 单元格 7% 淡色标记深色下不可见；浅色浮层/右键菜单背景偏透明压数据可读性差（深色正常）；设置抽屉半透明透底；设置齿轮用 PNG 位图而其他图标全是内联 SVG；底部单元格详情条（约 190px 常驻）无栏目标题无分隔线，像布局漏洞。
